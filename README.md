- **SQL & Armazenamento Analítico:** SQL (junções, agregações, filtros e modelagem relacional até 3FN), DuckDB e arquitetura Lakehouse local com Apache Parquet (compressão Snappy).

- **IA Aplicada & Qualidade de Código:** Uso supervisionado de LLMs/VLMs (*Schema Grounding*, JSON Schema e *Human-in-the-Loop*), Clean Code e versionamento semântico (Conventional Commits).
